# Changelog

All notable changes to TeamThink follow [Semantic Versioning](https://semver.org/).

## 0.15.0 — Phase 6: enterprise, PWA, self-host

- Docker Compose and Helm chart for self-host omnibus
- PWA manifest and service worker for installable mobile/desktop web
- SSO/SAML stub, SCIM user list, Stripe billing meter hook
- Data residency and compliance audit export API
- Air-gapped model mirror settings
- i18n messages (en, es, de, ja)
- Status page for signaling SLA
- SBOM generation in CI

## 0.14.0 — Phase 5: developer platform & integrations

- OpenAPI spec (`/openapi.yaml`, `/openapi.json`)
- MCP server export (`/mcp` on Worker and desktop gateway)
- Webhooks CRUD and event dispatch
- Integrations panel (embed SDK, Zapier/n8n docs)
- Evaluation harness and dataset sharing
- Plugin marketplace and LoRA adapter hub
- OpenTelemetry-style traces and Prometheus `/metrics`
